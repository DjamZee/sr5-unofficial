# Shadowrun 5 (unofficial) — système pour Foundry VTT

![Seattle depuis les toits](.github/readme/accueil-seattle-toits.webp)

*[English below](#english)*

Une mise en œuvre **non officielle** de la cinquième édition du jeu de rôle Shadowrun pour Foundry VTT (V13), en
français et en anglais. Projet de fans, gratuit, **sans lien avec Catalyst Game Labs, The Topps Company ni Black Book
Editions**.

Il prolonge le système `sr5` créé par **Karmaroms** et **deurk** (avec Michel_Platinium), repris et poursuivi par DjamZ
depuis 2026. Version actuelle : **1.0** (numéro technique 13.1.0 : le premier chiffre suit la version de Foundry).

## Ce que contient le système (et ce qu'il ne contient pas)

- Les règles sont **automatisées** : calculs de la fiche, combat (portées, modes de tir, recul, dispersion, défenses),
  magie (sorts, esprits, Drain, préparations), Matrice (marks, dommages, biofeedback, choc d'éjection, Score de
  Surveillance), rigging, poursuites, social, boutique, et une aide contextuelle sur chaque calcul.
- Des compendiums d'objets, d'archétypes et de tables (Mégapack Lite) : **noms, chiffres et renvoi à la page du livre**,
  sur le modèle de Chummer.
- **Aucun texte des livres.** Les descriptions disent ce que fait l'objet ou l'état et renvoient à la page (« SR5 p. 432 ») :
  il vous faut vos livres pour le texte complet.
- Un manuel intégré (compendium « Manuel ») et un [wiki](https://github.com/DjamZee/sr5-unofficial/wiki).

## Installation

Dans Foundry VTT, écran **Systèmes de jeu** → **Installer un système**, collez dans le champ *URL du manifeste* :

```
https://github.com/DjamZee/sr5-unofficial/releases/latest/download/system.json
```

Les mondes créés avec une version précédente du système (`sr5`, alpha « djamz ») se mettent à jour normalement.

# Shadowrun 5 (unofficial) — system for Foundry VTT

An **unofficial** implementation of the Shadowrun fifth edition roleplaying game for Foundry VTT (V13), in French and
English. A free fan project, **not affiliated with Catalyst Game Labs, The Topps Company or Black Book Editions**.

It carries on the `sr5` system created by **Karmaroms** and **deurk** (with Michel_Platinium), taken over by DjamZ in
2026. Current version: **1.0** (technical number 13.1.0: the first digit follows the Foundry version).

## What the system holds (and what it does not)

- **Automated rules**: sheet calculations, combat (ranges, firing modes, recoil, scatter, defenses), magic (spells,
  spirits, Drain, preparations), the Matrix (marks, damage, biofeedback, dumpshock, Overwatch Score), rigging, chases,
  social tests, a shop, and contextual help on every calculation.
- Compendiums of items, archetypes and tables (Megapack Lite): **names, numbers and the book page**, the Chummer way.
- **No text from the books.** Descriptions say what an item or a condition does and point to the page ("SR5 p. 431"):
  you need your books for the full text.
- A built-in manual ("Manuel" compendium) and a [wiki](https://github.com/DjamZee/sr5-unofficial/wiki).

## Installation

In Foundry VTT, **Game Systems** → **Install System**, paste in the *Manifest URL* field:

```
https://github.com/DjamZee/sr5-unofficial/releases/latest/download/system.json
```

Worlds made with an earlier version of the system (`sr5`, "djamz" alphas) update as usual.
